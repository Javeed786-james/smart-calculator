# Smart Calculator

A simple and responsive calculator web application built using HTML, CSS, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Decimal calculations
- Clear button
- Backspace button
- Division-by-zero error handling
- Keyboard support
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use
mmm
1. Open the calculator.
2. Enter numbers using the buttons or keyboard.
3. Select an arithmetic operator.
4. Enter the second number.
5. Press `=` to get the result.
6. Use `C` to clear the calculator.
7. Use `←` to delete the last digit.
